Privacy Policy for GreenBot
Effective Date: April 14, 2026

Introduction
This Privacy Policy outlines how GreenBot ("the Bot," "we," "us," "our") collects, uses, and stores information when you interact with it on Discord ("the Service").

**Data collection is opt-in by interaction.** The Bot does not collect, store, or process any data about you unless you directly interact with it first (by mentioning it, replying to it, or messaging it in DMs). If you have never interacted with the Bot, no data about you is stored.

1. Information We Collect
All data is stored locally on the private server hosting the Bot and is never shared with third parties.

User-Provided Content:

Message Content (Memory): When you directly interact with the Bot, the content of your messages is saved to a private text file associated with your User ID. This serves as conversational context for future interactions. No data is collected from users who have not directly interacted with the Bot.

Media Files: The Bot scans messages for media attachments and URLs (images, GIFs, videos). If a file meets the configured criteria (valid file type, under 50MB), a copy may be downloaded and stored in a local media pool on the server.

Suggestions: When you use the /suggest command, your suggestion text, username, and User ID are posted to a designated channel within the server.

Discord User Information:

User ID and username are stored solely to associate you with your own data (memory file, suggestions).

2. How We Use Your Information
Data collected is used exclusively for:

- Generating AI responses and maintaining conversational memory across sessions.
- Executing slash commands (/health, /mem, /suggest, /todo).
- Enabling the random media interjection feature.
- Allowing the Bot Owner to administer the media pool.
- Logging and debugging to ensure Bot stability.

3. Data Storage, Retention, and Security
Storage: All data is stored in private files on the Bot's host server. No data is sent to third-party services.

Data Retention:
- User Memory: Automatically pruned to a maximum of 300 lines. Oldest messages are removed as new ones are added.
- Media Pool: Automatically pruned to a maximum of 100 files. Oldest files are removed as new ones are added.

Security: Reasonable measures are taken to secure the server and its data. No online service can be guaranteed 100% secure.

4. Your Rights and Data Control
You have direct control over your stored data at any time.

Accessing Your Data: Use /mem show to view a recent snippet of your stored message history.

Deleting Your Data: Use /mem clear to permanently delete your entire message history from the server.

Media Removal: To have specific media you posted removed from the Bot's pool, contact the Bot Owner directly.

Opting Out: Because data collection is triggered only by direct interaction, you can opt out at any time simply by not interacting with the Bot. To have existing data removed, use /mem clear or contact the Bot Owner.

5. Changes to This Privacy Policy
This policy may be updated periodically. Significant changes will be announced in a designated channel within the Discord server.
